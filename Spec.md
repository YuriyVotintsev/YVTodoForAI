# AI Review Comments Plugin для JetBrains Rider

Плагин позволяет создавать code review комментарии прямо в IDE и экспортировать их для передачи ИИ-ассистенту. ИИ исправляет код по комментариям и отмечает выполненные задачи в JSON-файле, который плагин автоматически подхватывает.

## Как это работает

Разработчик выделяет код в редакторе, нажимает хоткей и вводит комментарий — что нужно исправить или улучшить. Все комментарии отображаются в отдельном Tool Window, откуда можно перейти к нужному месту в коде, отредактировать или удалить комментарий.

Когда комментарии готовы, разработчик передаёт их ИИ. После внесения исправлений ИИ обновляет статусы в JSON-файле проекта, и плагин автоматически помечает соответствующие комментарии как выполненные.

## Хранение данных

Комментарии хранятся в файле `.ai-review-status.json` в корне проекта.

## Модель комментария

```kotlin
data class ReviewComment(
    val id: String,
    val filePath: String,
    val startLine: Int,
    val endLine: Int,
    val selectedText: String,
    val comment: String,
    val status: Status,
    val createdAt: Long
)

enum class Status { PENDING, DONE }
```

## Добавление комментария

Хоткей `Ctrl+Alt+/` открывает popup с текстовым полем. Работает только когда в редакторе выделен текст. Комментарий сохраняется вместе с информацией о файле, номерах строк и выделенном коде.

## Tool Window

Окно "AI Review" показывает список всех комментариев с возможностью фильтрации по статусу. Двойной клик открывает файл и переходит к нужной строке. Через контекстное меню можно редактировать, удалять комментарии и менять их статус.

## Подсветка в редакторе

Строки с комментариями подсвечиваются приглушённым фоном прямо в редакторе. При открытии файла плагин проверяет, есть ли для него комментарии, и добавляет highlighting на соответствующие строки. Подсветка обновляется при добавлении, удалении комментариев и изменении их статуса.

При наведении курсора на подсвеченные строки с небольшой задержкой появляется tooltip с текстом комментария.

## Интеграция с ИИ

ИИ работает напрямую с файлом `.ai-review-status.json`. Файл содержит все комментарии со всей информацией. После исправления кода ИИ меняет статус комментария на `done`. FileWatcher в плагине отслеживает изменения файла и обновляет UI.
